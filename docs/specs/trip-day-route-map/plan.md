## 검증에서 확인하지 못한 것

- 실제 폰에서 손가락으로 손잡이를 끄는 동작. 터치 포인터 이벤트로만 확인했다.
- 별도 브라우저·기기에서 같은 계정으로 여는 것(AC9). 새로고침과 계정 전환으로 저장이 유지되는 것은 확인했다.

## 알아 둘 점

- 멤버와 초대에는 이메일이 표시된다. 닉네임은 다음 작업(유저 프로필)에서 다룬다.
- Supabase 보안 점검 경고 3건(`invite_to_trip`, `list_my_invitations`, `list_trip_members`가 security definer)은 의도한 설계다. 함수 안에서 만든 사람·멤버인지 먼저 확인한다.
- 테스트 계정 세 개(`tourdiary.*@example.com`)와 테스트 여행이 Supabase DB에 남아 있다.
- 모든 커밋 메시지 끝에 `Spec-Folder: docs/specs/trip-day-route-map/`을 붙인다.
- `.env.local`의 값은 사용자가 직접 입력한다. 이 파일은 git에 들어가지 않는다.
